# FigmaCN

Figma 网页版的浏览器扩展。打开 Figma 时自动汉化菜单、面板和提示。需要翻译设计文案时，可在浏览器侧栏生成译文并对照预览。

[查看更新日志](CHANGELOG.md)

## 安装或升级

1. 在 GitHub 仓库点击「Code → Download ZIP」并解压。已有本地仓库可用 `git pull` 更新。
2. 打开 Edge 的 `edge://extensions`（Chrome 为 `chrome://extensions`），开启「开发人员模式」。
3. 初次安装时点「加载解压缩的扩展」，选择包含 `manifest.json` 的目录。已安装且已更新原目录时，在 FigmaCN 卡片上点「重新加载」。
4. 刷新 Figma 网页。界面汉化无需配置 API。

## 首次配置翻译 API

1. 点击浏览器工具栏上的 FigmaCN 图标打开侧栏。图标未固定时，可从浏览器的「扩展」菜单打开 FigmaCN 侧栏。
2. 点击侧栏右上角的「设置」，选择 DeepSeek、Gemini 或 OpenAI。默认使用 DeepSeek 的 `deepseek-flash`，可改为该服务中你有权限使用的模型。
3. 在设置页输入所选服务的 API Key，点击「保存设置」，再切回 Figma 和侧栏。

同一个浏览器配置下，重开侧栏或重启浏览器后可继续使用。只改同一服务的模型时，Key 一栏可以留空。切换服务时请输入新服务对应的 Key。修改或清除 Key 也在此设置页完成。

## 翻译一组文案

1. 从 Figma 文字图层复制原文，粘贴进侧栏的「图层原文」。可以先用以下两行试跑：

   ```text
   Save changes
   Continue to checkout
   ```

2. 保持「逐行翻译」开启，让每条短文案分别预览。如果这几行属于同一个图层的一段文字，可关闭该选项，让模型结合上下文翻译。
3. 在「目标语言」输入 `简体中文`。也可输入 `简体中文、日本語` 一次生成多份。可在「术语或语气要求」补充品牌名、术语表或语气。
4. 点「生成译文」并审阅。点「复制这条」复制一个图层的译文，或点「复制全部」复制该语言的整份译文。
5. 若要保留原设计，先在 Figma 复制画框，再进入副本中对应的文字图层粘贴译文。扩展通过侧栏处理文案，画框复制和文字写回由 Figma 编辑器完成。

### 数据去向与排查

- API Key 保存在当前浏览器的扩展存储中，未加密，也不会随浏览器账号同步。只在扩展设置页输入 Key。
- 点击「生成译文」时，粘贴的原文、目标语言及填写的翻译要求会发送给所选服务。
- 提示 Key 无效或无权限时，请核对服务与 Key 是否对应，并确认模型权限。提示响应超时时，可缩小翻译批次后重试。

界面词条可在 [现行词库](js/web-dictionary.js) 和 [翻译脚本](js/content.js) 中维护。
