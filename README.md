# FigmaCN

Figma 网页版的本地浏览器扩展。自动汉化网页界面，并通过侧栏翻译手动粘贴的设计文案。

## 安装

1. 打开 Edge 的 `edge://extensions`（Chrome 为 `chrome://extensions`）。
2. 开启「开发人员模式」。
3. 点击「加载已解压的扩展程序」，选择本目录。
4. 如果已经安装 FigmaCN，点「重新加载」即可。然后刷新 Figma 网页。

## 图层译写

1. 点击浏览器工具栏中的 FigmaCN 图标打开侧栏。如果图标未固定，可在浏览器的「扩展」菜单找到它。
2. 在 Figma 里复制文字图层的原文，再粘贴进侧栏。多条短文案可以逐行翻译。单个图层内的多段文字可取消「逐行翻译」。
3. 选择 DeepSeek、Gemini 或 OpenAI，填入对应 API Key 和目标语言，点击「生成译文」。
4. 审阅原文与译文，逐条复制，粘贴到画框副本中的对应文字图层。也可复制某种语言的完整译文。

侧栏使用本次会话内的 API Key。只有点击生成时才会把粘贴的原文和翻译要求发送给所选服务。侧栏没有画布写入权限，画框复制及文字粘贴在 Figma 内完成。

网页界面词条在 `js/content.js` 和 `js/web-dictionary.js` 中维护。
